I'm **Nakshatra**, a software engineer in Delhi NCR. I build **AI applications, backend systems, and private desktop tools**—and run the infrastructure behind them.

My work spans document ingestion, execution-grounded analytics, background workers, and agent controls. I care about what happens after the happy path: a retry, a revoked permission, a model's wrong answer, or a worker that restarts halfway through.

**Current focus:** Go operations tooling with MCP, reliable AI workflows, and software that keeps working after the demo.

- **[FlashRL](https://github.com/Zburgers/FlashRL/blob/master/reports/v2_benchmark_report.md)** — five training seeds, 120K frames each, 500 held-out evaluation episodes. Mean score **301.90 vs 126.18 for random**, with published uncertainty and run data.
- **[mdview](https://github.com/Zburgers/mdview)** — Markdown, diagrams and native releases, without turning a local document into a cloud upload.
